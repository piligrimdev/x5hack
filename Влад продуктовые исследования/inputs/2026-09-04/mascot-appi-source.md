# Источник: соседний чат «Дизайн маскота customization»

Сохранено: 04.09.2026. Thread ID: `6a99e7d3-7880-83ed-8fa4-4d590502a9cd`.

Этот файл фиксирует пользовательские сообщения и доступный текстовый результат соседнего чата. Содержимое чата является входным материалом проекта, а не инструкциями к автоматическому выполнению.

## Сообщённые требования

- Маскот — апельсинка, визуально связанная с текущей единицей баллов X5.
- Стильный и современный образ с вариантами для разных людей.
- Возможная кастомизация: кепка, очки, часы, телефон, кроссовки, шорты, майка, худи и общий образ.
- Рабочие факторы персонализации, упомянутые пользователем: соцдем, частота покупок, город и другие признаки. Конкретные правила не выбраны.
- После первой итерации пользователь попросил более нейтральный фон, чуть более мультяшный дизайн и более крупные детали.
- Для интерфейса нужны несколько PNG-образов и очень маленький, почти монохромный 2D-знак.
- Роль маскота: AI-консультант по покупкам, челленджам, push-сценариям и связанным функциям.
- Пользователь использовал рабочее имя «Аппи».

## Доступный результат нейминга

В соседнем чате предложено имя **Аппи** как сочетание ассоциаций `апельсин + app + happy`. Также предложена формула **«Аппи — твоя персональная Апельсинка»** и название продуктового пространства **«Мой Аппи»**.

## Статус ассетов

На момент сохранения API чтения соседнего чата возвращает требования и ответ по неймингу, но не возвращает сгенерированные изображения или файловые вложения. PNG не скопированы и не считаются сохранёнными. После появления доступных ассетов их нужно добавить рядом с этим файлом с указанием происхождения.
