# Что такое n8n и зачем он в product discovery

n8n — визуальный конструктор автоматизаций. Workflow состоит из связанных узлов: один получает входные данные, другой ищет или читает информацию, третий обращается к ИИ, следующий преобразует и сохраняет результат. Можно связывать сервисы через их API с небольшим количеством кода. [Официальная документация](https://docs.n8n.io/).

Для нашего процесса возможна цепочка:

**Бриф → поиск аналогов → чтение источников → карточки механик → выбор Влада → сегменты и вопросы → гипотезы → сохранение в файлы/таблицу.**

Это иллюстрация организации процесса, не новый выполненный workflow. Полезность n8n — повторяемость, передача структурированных результатов между шагами и автоматическое сохранение. Он не определяет сам, какая идея нужна людям, и не превращает синтетическое интервью в исследование реальных клиентов.

Наш `AI_Product_Discovery.json` описывает такой маршрут из 22 узлов. Сейчас его исследовательскую логику выполняет Codex доступными инструментами, с остановками для решений Влада. Сам n8n не запускался: исходник имеет ошибку экранирования строки, а подключение сервисов и ключей отдельно не настраивалось. Оригинал сохранён, карта структуры — [workflow-map.json](workflow-map.json).

Для текущего разового исследования отдельный запуск n8n не нужен. Он может пригодиться позднее, если команда захочет регулярно повторять одну и ту же цепочку для новых сегментов, источников или тестов качества — это рекомендация ассистента, не выбранный технический план.
