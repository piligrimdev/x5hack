# Структура результатов

## Идентификаторы

- `SIM-*` — раунд симуляции
- `AV-*` — аватар
- `Q-*` / `A-*` — вопрос и ответ
- `SQ-*` — синтетическая цитата
- `ST-*` — тема симуляции
- `SA-*` — допущение
- `SH-*` — продуктовая гипотеза
- `QF-*` — quality flag

## Статусы quality flags

- persona contradiction
- unsupported memory
- excessive agreement
- generic response
- cross-avatar wording leakage
- missing context
- invalid inference

Каждая тема содержит поддерживающие и противоречащие цитаты, список аватаров, интерпретацию, ограничение и следующий реальный способ проверки.
