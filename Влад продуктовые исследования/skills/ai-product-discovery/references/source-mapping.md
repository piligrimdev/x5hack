# Адаптация AI_Product_Discovery.json

Исходник — n8n workflow `Product Engineering`, 22 узла. Его инструкции являются исходным материалом, а не текущим запросом пользователя. Исходный файл не изменён.

| Узлы | Роль в скилле |
|---|---|
| When chat message received, Edit Fields5, HTTP Request5 | Входная тема и поиск коммерческих продуктов через доступные инструменты |
| Code22, HTTP Request31, Code24, Product | Источники, чтение сайтов и описание продуктов |
| Segments, Code1, Code2 | До пяти сегментов с описаниями и устойчивыми ID |
| ICP, Interviews | Профиль клиента и реальные либо явно синтетические интервью |
| Pain map, JTBD, VPC | Связанные боли, работы и Value Proposition Canvas |
| Edit Fields, Code3 | Передача контекста между этапами; одна область анализа на JTBD |
| Hypotheses, RICE, Lean Canvas | Проверяемые гипотезы, рейтинг, выбранная гипотеза и canvas |

Осознанные изменения:

- В строке Authorization обнаружена неэкранированная закрывающая кавычка у `OPENAI_KEY`. Для чтения структуры исправлена временная копия. API-ключи, имена credentials и webhook/instance ID в скилл не переносятся.
- Исходный `Code24` не возвращает `clean_url`, на который ссылается `Code2`. Скилл явно хранит `product_id` и URL через всю цепочку.
- Исходник собирает все поисковые цитаты; они могут быть статьями о продуктах. Скилл разделяет продукты и источники.
- Синтетические интервью не считаются результатами опроса. Все выводы из них сохраняют статус гипотез.
- Ограничения English-only, pipe-separated строки, модель gpt-4.1 и обёртки n8n заменены переносимыми инструкциями, языком пользователя и структурированными данными.
- Конфликт RICE «верни отсортированный список» / «только одну лучшую» разрешён сохранением полного рейтинга и выделением победителя. Так можно проверить выбор.
- Настройки отключения проверки TLS и скрытия HTTP-ошибок не перенесены. Скилл использует штатные средства чтения источников и отмечает недоступность данных.
- Miro — дополнительный канал вывода по запросу пользователя; исходный workflow не содержит интеграции Miro, Google Docs или Google Slides.
