# Адаптация воркшопа SDD

Основа — предоставленный пользователем воркшоп Яна Анисимова «Spec-Driven Development для AI-агентов», 26 страниц, 03.09.2026.

Принято в методику:

- спецификация как основной контракт поведения;
- релевантный контекст и `AGENTS.md` как якоря;
- цепочка constitution → specify → clarify → plan → tasks → implement → converge;
- проверка согласованности требований, задач и реализации;
- человеческие контрольные точки перед существенными решениями.

Адаптировано:

- на первой странице заявлены шесть стадий, но рабочая последовательность слайдов содержит семь; скилл использует семь;
- число и длительность задач считаются эвристикой;
- spec включает продуктовые метрики и отдельный контракт AI/ML;
- SDD объединяется с существующим GSD: SDD отвечает за контракт и convergence, GSD — за оркестрацию и состояние.

Не принято как универсальное требование:

- конкретный стек, Clean Architecture, строгий TDD, Database First, REST/WebSocket;
- установка GitHub Spec Kit/OpenSpec или версия CLI из слайдов без проверки актуальной документации;
- автоматическое создание issues, commits и PR;
- выполнение учебного упражнения над текущим проектом без отдельной задачи на разработку.
