## Страница 10

Установка (актуальная версия — 1.0.1)
uv tool install specify-cli --from git+https://github.com/github/spec-kit.git@v1.0.1
Проверь: specify version или specify check[5].
Обновление/апгрейд (самоменеджмент CLI):
specify self check                # есть ли новая версия (read-only)
specify self upgrade --dry-run    # предпросмотр без установки
specify self upgrade              # обновить до последнего релиза
specify self upgrade --tag v1.0.1 # закрепить конкретный тег
Для существующих проектов: specify init . --integration claude --
here[5].

## Страница 12

Первые команды в AI-агенте
Открой проект в Cursor/Claude: / покажет команды.
1. /speckit.constitution — принципы проекта
2. /speckit.specify — User Stories + API
3. /speckit.clarify — уточнение неясного
4. /speckit.plan — план файлов
5. /speckit.tasks — 10-20 задач
6. /speckit.analyze — проверка согласованности спеки/плана/задач
7. /speckit.implement — код по задачам
8. /speckit.converge — сверка кода со спекой, остаток → новые задачи
9. /speckit.taskstoissues — задачи → GitHub issues
10. /speckit.checklist — кастомные чек-листы качества

## Страница 17

Этап 1 - Constitution
Что: "ДНК" проекта (стандарты, стек).
Шаблон (скопируй в constitution.md):
## Принципы разработки
1. **Clean Architecture** - четкое разделение слоев
2. **Type Safety** - TypeScript на клиенте и Python3.11 сервере
3. **REST + WebSocket** - REST API + real-time
4.  **TDD (Test-Driven Development)** — разработка через тестирование:
    - _Red_: Написание провального теста перед кодом.
    - _Green_: Написание минимально необходимого кода для прохождения теста.
    - _Refactor_: Улучшение кода при сохранении работоспособности тестов.
5. **Database First** - схема БД определяет API

## Страница 18

Этап 2 - Specify
Что: Markdown spec с User Stories, API, БД.
Шаблон myfeature_spec.md:
# Specify: [Название фичи]
## User Stories
- Как [user], я хочу [действие] чтобы [польза]
## API
- POST /api/[endpoint] {schema}
## БД
- Таблица [name]: поля...
## Ограничения
- Edge cases: [список]
Задание: Напиши 2-3 stories для своей фичи.

## Страница 21

Этап 5 - Tasks
Что: 10-20 атомарных задач (todo-лист).
Шаблон:
## Tasks
- [ ] Task1: [file] + tests

Задание: Разбей Plan на 10 задач. Стандарт: testable, <15 мин каждая.

## Страница 22

Этап 6 - Implement
Что: AI выполняет по задачам, с тестами/checkpoints.
Процесс:
1. AI: "Implement Task1 из spec."
2. Run tests/linter.
3. Commit only if green.
Задание: Выбери 1 task, сгенерируй код в AI. Не коммить — просто проверь.

## Страница 23

Этап 7 - Converge
Что: Сверка кода со спекой/планом/задачами.
AI оценивает: всё ли реализовано, нет ли расхождений с spec.
Несделанное/сломанное →  добавляется как новые задачи (возврат к
этапу 5).
Повторяй implement →  converge, пока /speckit.converge не отчитается
Converged.
Задание: Запусти /speckit.converge по своей фиче. Если выдал новые
задачи — обнови spec и закрой их.
