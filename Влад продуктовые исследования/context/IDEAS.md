## Гипотезы из Qwen-пакета

SRC-07, часть 6. Авторские оценки риска не приняты как решение команды. Подробные механики, поля данных, формулы и числовые пороги остаются в исходном файле как предложения.

| Локальный ID | Исходный ID | Содержание черновика |
|---|---|---|
| QW-H1 | H1 | Персональный челлендж эффективнее общей промоакции по частоте |
| QW-H2 | H2 | Кросс-сетевой челлендж повышает кросс-продажи |
| QW-H3 | H3 | Экономия и аватар увеличивают возвраты без push |
| QW-H4 | H4 | Анонимный локальный рейтинг повышает вовлечённость |
| QW-H5 | H5 | Реферальная награда после покупки улучшает качество приглашений и снижает фрод |
| QW-H6 | H6 | LLM даёт ≥70% релевантности при приемлемой цене/задержке; в источнике назван главным риском |
| QW-H7 | H7 | Партнёрские челленджи стимулируют trial без сильного падения маржи |
