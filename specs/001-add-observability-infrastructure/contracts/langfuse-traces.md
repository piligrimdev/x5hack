# Langfuse Traces Contract

**Версия**: 1.0  
**Дата**: 2026-09-05

## Обзор

Langfuse отслеживает все LLM вызовы к OpenRouter, захватывая токены, latency, стоимость и user_id для атрибуции и анализа.

---

## Trace Structure

### LLM Trace

```python
Trace {
    # Identifiers
    id: UUID              # Generated by Langfuse SDK
    user_id: UUID         # Extracted from request context (contextvars)
    session_id: UUID      # Optional; groups related traces
    
    # Model Info
    model: str            # "anthropic/claude-haiku-4.5"
    
    # Tokens
    input_tokens: int     # From OpenRouter response.usage.prompt_tokens
    output_tokens: int    # From OpenRouter response.usage.completion_tokens
    total_tokens: int     # input_tokens + output_tokens
    
    # Timing
    start_time: ISO8601   # When trace started
    end_time: ISO8601     # When trace ended
    latency_ms: int       # (end_time - start_time) in milliseconds
    
    # Cost
    cost_usd: float       # Calculated from tokens + model rates
    
    # Status
    status: str           # "success" or "error"
    error_type?: str      # If status="error", e.g., "RateLimitError"
    error_message?: str   # Exception message
    
    # Context
    request_id: str       # HTTP request ID (if applicable)
    metadata: dict        # Extra fields (e.g., challenge_type, user_preferences)
    
    # Input/Output (optional, for debugging)
    input?: str           # System + user prompt (truncated if too long)
    output?: str          # Model response (truncated if too long)
}
```

## SDK Integration Pattern

### Minimal Wrapper (Recommended)

```python
# core/llm.py
from langfuse import Langfuse
from contextvars import ContextVar

# Initialize once in main()
langfuse_client = Langfuse(
    api_key=os.getenv('LANGFUSE_API_KEY'),
    secret_key=os.getenv('LANGFUSE_SECRET_KEY'),  # optional
    enabled=os.getenv('LANGFUSE_ENABLED', 'true').lower() == 'true'
)

# Context variable (shared with structlog)
user_id_context: ContextVar[str] = ContextVar('user_id', default=None)

def call_openrouter_tools_traced(
    model: str,
    system: str,
    user: str,
    tools: list[dict],
    api_key: str | None = None,
    timeout: float = 30.0,
    max_retries: int = 3,
) -> list[ToolCall]:
    """
    Wraps call_openrouter_tools() with Langfuse tracing.
    Extracts user_id from context; falls back to None if unavailable.
    """
    
    user_id = user_id_context.get()
    
    with langfuse_client.trace(
        name="openrouter_completion",
        metadata={
            "user_id": user_id,
            "model": model,
            "tools_count": len(tools),
        }
    ) as trace:
        start_time = time.time()
        
        try:
            # Call OpenRouter (existing implementation)
            resp = httpx.post(
                OPENROUTER_URL,
                headers={"Authorization": f"Bearer {api_key}"},
                json={
                    "model": model,
                    "messages": [
                        {"role": "system", "content": system},
                        {"role": "user", "content": user},
                    ],
                    "tools": tools,
                    "tool_choice": "auto",
                    "temperature": 0.2,
                },
                timeout=timeout,
            )
            resp.raise_for_status()
            data = resp.json()
            
            # Extract usage
            usage = data["choices"][0].get("usage", {})
            input_tokens = usage.get("prompt_tokens", 0)
            output_tokens = usage.get("completion_tokens", 0)
            
            # Log to Langfuse
            latency_ms = int((time.time() - start_time) * 1000)
            trace.event(
                name="completion",
                input={
                    "system": system[:500],  # truncate for storage
                    "user": user[:500],
                    "tools_count": len(tools),
                },
                output={
                    "choices_count": len(data.get("choices", [])),
                    "finish_reason": data["choices"][0].get("finish_reason"),
                },
                metadata={
                    "input_tokens": input_tokens,
                    "output_tokens": output_tokens,
                    "latency_ms": latency_ms,
                    "user_id": user_id,
                }
            )
            
            # Parse and return tool calls
            raw_calls = data["choices"][0]["message"].get("tool_calls") or []
            result: list[ToolCall] = []
            for call in raw_calls:
                fn = call.get("function", {})
                name = fn.get("name")
                if not name:
                    continue
                try:
                    arguments = json.loads(fn.get("arguments", "{}"))
                except json.JSONDecodeError:
                    continue
                result.append(ToolCall(name=name, arguments=arguments))
            
            return result
            
        except Exception as e:
            # Log error to Langfuse
            latency_ms = int((time.time() - start_time) * 1000)
            trace.event(
                name="error",
                input={
                    "system": system[:500],
                    "user": user[:500],
                },
                metadata={
                    "error_type": type(e).__name__,
                    "error_message": str(e),
                    "latency_ms": latency_ms,
                    "user_id": user_id,
                }
            )
            raise
```

## Graceful Degradation

### If Langfuse Unavailable

```python
def call_openrouter_tools_traced(...) -> list[ToolCall]:
    user_id = user_id_context.get()
    
    try:
        with langfuse_client.trace(...):
            return call_openrouter_tools(...)
    except Exception as e:
        # Log to structlog as fallback
        structlog.get_logger().warning(
            "langfuse_trace_failed",
            user_id=user_id,
            error_type=type(e).__name__,
            error_message=str(e)
        )
        # Continue without Langfuse
        return call_openrouter_tools(...)
```

## Langfuse SQL Schema (Reference)

Langfuse manages internal schema; these are the exposed fields via API:

```sql
-- Conceptual representation
CREATE TABLE traces (
    id UUID PRIMARY KEY,
    project_id UUID,
    user_id VARCHAR(255),
    session_id UUID,
    name VARCHAR(255),
    metadata JSONB,
    
    start_time TIMESTAMP,
    end_time TIMESTAMP,
    
    created_at TIMESTAMP DEFAULT NOW(),
    
    INDEX (project_id, user_id),
    INDEX (created_at)
);

CREATE TABLE trace_events (
    id UUID PRIMARY KEY,
    trace_id UUID,
    name VARCHAR(255),  -- "completion", "error"
    input JSONB,
    output JSONB,
    metadata JSONB,
    created_at TIMESTAMP,
    
    FOREIGN KEY (trace_id) REFERENCES traces(id),
    INDEX (trace_id)
);
```

## Cost Calculation

Langfuse автоматически вычисляет затраты на основе token counts и model rates.

**Formula**:
```
cost_usd = (input_tokens * input_rate + output_tokens * output_rate) / 1000
```

**Example for Claude Haiku**:
```
input_rate = $0.80 per 1M tokens
output_rate = $4.00 per 1M tokens

For 250 input tokens + 150 output tokens:
cost = (250 * 0.80 + 150 * 4.00) / 1000
     = (200 + 600) / 1000
     = 0.0008 USD
```

## Data Retention & Privacy

- **Retention**: Loki/Langfuse will retain traces for 30 days (default; configurable)
- **Privacy**: user_id is anonymized UUID; no PII stored
- **Deletion**: On-demand deletion available via Langfuse API (not in scope for v1)

## Validation Checklist

- [ ] Langfuse SDK initialized with valid API key
- [ ] user_id extracted from request context or contextvars
- [ ] Every OpenRouter call wrapped in Langfuse trace
- [ ] Input/output truncated to prevent oversized logs
- [ ] Error traces include error_type and error_message
- [ ] Token counts always populated (from OpenRouter response.usage)
- [ ] Graceful degradation if Langfuse unavailable
- [ ] No PII in trace metadata
